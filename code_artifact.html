หลักการที่ใช้

N = mg cosθ

mg sinθ
องค์ประกอบของแรงโน้มถ่วงตามแนวพื้นเอียง (แรงดึงลง)

แรงเสียดทานจลน์ต้านการไถลลงตามพื้นเอียง
ΣF = mg sinθ - fk

a = ΣF / m
