## รายละเอียดโปรเจกต์
สื่อการเรียนรู้เชิงปฏิสัมพันธ์วิชาฟิสิกส์ เรื่องแรงเสียดทานสถิตและแรงเสียดทานจลน์ สำหรับนักเรียนและครูผู้สอน

### 2 โหมดการจำลองหลัก
1. **[ พื้นราบ ]**:
   - คำนวณ: $N = mg$, $f_{s,\max} = \mu_s N$, $f_k = \mu_k N$, $F_{\text{ลัพธ์}} = F - f_k$, $a = F_{\text{ลัพธ์}} / m$
   - มีปุ่มโหลดค่ามาตรฐานตามใบงานการทดลองที่ 1 ($m = 2\text{ kg}, F = 10\text{ N}, \mu_s = 0.4, \mu_k = 0.2, g = 10\text{ m/s}^2$)
2. **[ พื้นเอียง ]**:
   - คำนวณ: $N = mg\cos\theta$, $mg\sin\theta$, $f_{s,\max} = \mu_s N$, $f_k = \mu_k N$, $F_{\text{ลัพธ์}} = mg\sin\theta - f_k$, $a = F_{\text{ลัพธ์}} / m$
   - มีปุ่มโหลดค่ามาตรฐานตามใบงานการทดลองที่ 2 ($m = 2\text{ kg}, \theta = 30^\circ, \mu_s = 0.4, \mu_k = 0.2, g = 10\text{ m/s}^2$)

### คุณสมบัติเด่น
- **ภาพ Free-body Diagram สไตล์ชีทโจทย์ฟิสิกส์**:
  - ลายแรเงาใต้พื้นผิว (`///`)
  - ทางลาดสามเหลี่ยมมุมฉากพร้อมสัญลักษณ์มุมฉากและมุม $\theta$ ที่ฐาน
  - ลูกศรแรงแยกสีชัดเจน ($N, mg, mg\sin\theta, mg\cos\theta, F, f, v$) ไม่ซ้อนทับกัน
  - เส้นประแสดงการแตกแรงเวกเตอร์ตามหลักฟิสิกส์
- **ระบบ Animation ที่สมจริง**:
  - กล่องเคลื่อนที่จริงตามค่าความเร่ง และหยุดที่ปลายพื้นอย่างถูกต้อง ($v = 0$) ไม่วนซ้ำ
  - สามารถกดเริ่มการทดลองใหม่อีกครั้งเพื่อเริ่มรอบใหม่จากจุดเริ่มต้นได้ทันที
- **ระบบช่วยเรียนรู้**:
  - แสดงหลักการและสูตรที่ใช้
  - แสดงวิธีคำนวณทีละขั้นตอนแบบไดนามิก (แทนค่าตัวเลขตามแถบเลื่อนจริง)
  - สรุปผลการทดลองและตรวจสอบความสอดคล้องกับทฤษฎี
- **ภาษาไทย 100%**: ทุกข้อความบนหน้าเว็บเป็นภาษาไทยเข้าใจง่าย
