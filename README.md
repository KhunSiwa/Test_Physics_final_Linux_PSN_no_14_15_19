## รายละเอียดโปรเจกต์
สื่อการเรียนรู้เชิงปฏิสัมพันธ์วิชาฟิสิกส์ เรื่องแรงเสียดทานสถิตและแรงเสียดทานจลน์ สำหรับนักเรียนและครูผู้สอน

### ฟีเจอร์หลัก
1. **การจำลอง 2 โหมด**:
   - **พื้นราบ**: คำนวณ $N = mg$, $f_{s,\max} = \mu_s N$, $f_k = \mu_k N$, $F_{\text{ลัพธ์}} = F - f_k$, $a = F_{\text{ลัพธ์}} / m$
   - **พื้นเอียง**: คำนวณ $N = mg\cos\theta$, $mg\sin\theta$, $f_{s,\max} = \mu_s N$, $f_k = \mu_k N$, $F_{\text{ลัพธ์}} = mg\sin\theta - f_k$, $a = F_{\text{ลัพธ์}} / m$
2. **ภาพ Free-body Diagram สไตล์ชีทโจทย์ฟิสิกส์**:
   - ลายแรเงาใต้พื้นผิว (`///`)
   - ทางลาดสามเหลี่ยมมุมฉากพร้อมสัญลักษณ์มุมฉากและมุม $\theta$ ที่ฐาน
   - ลูกศรแรงแยกสีชัดเจน ($N, mg, mg\sin\theta, mg\cos\theta, F, f, v$) ไม่ซ้อนทับกัน
   - เส้นประแสดงการแตกแรงเวกเตอร์ตามหลักฟิสิกส์
   - กล่องเคลื่อนที่จริงตามค่าความเร่ง และลูกศรแรงเคลื่อนที่ติดตามกล่อง
3. **ระบบช่วยเรียนรู้**:
   - หลักการและสูตรที่ใช้
   - แสดงวิธีคำนวณทีละขั้นตอนแบบไดนามิก (แทนค่าตัวเลขตามแถบเลื่อนจริง)
   - สรุปผลการทดลองและตรวจสอบความสอดคล้องกับทฤษฎี
   - ปุ่มโหลดค่ามาตรฐานตามใบงานการทดลองที่ 1 และ 2
   - แบบทดสอบท้ายบท 2 ข้อ พร้อมระบบตรวจคำตอบและเฉลยคำอธิบาย
4. **ภาษาไทย 100%**: รองรับการใช้งานของนักเรียนไทยอย่างสมบูรณ์
